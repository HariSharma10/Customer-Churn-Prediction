About This Project

The Customer Churn Prediction System is a machine learning web application developed to predict whether a telecom customer is likely to continue using the service or discontinue it. The prediction is based on customer details, subscribed services, contract information, and billing history.

Project Objective

The main objective of this project is to help telecom companies identify customers who may leave their services in advance. Early prediction enables businesses to take appropriate actions such as offering better plans, discounts, or improved customer support to increase customer retention.

Machine Learning Model

This project uses the Logistic Regression classification algorithm. The model was trained on the Telco Customer Churn dataset after preprocessing, label encoding, and feature scaling.

Dataset Information

  • Dataset: Telco Customer Churn
  • Total Features Used: 19
  • Target Variable: Churn
  • Customer Demographics
  • Internet & Phone Services
  • Contract Information
  • Billing Details

Technologies Used

  • Scikit-learn
  • Joblib
  • HTML5
  • CSS3

Project Workflow

  1. Load and clean the customer dataset.
  2. Encode categorical features.
  3. Scale numerical features.
  4. Train the Logistic Regression model.
  5. Save the trained model and preprocessing objects.
  6. Build a Flask web application.
  7. Accept customer details through the web interface.
  8. Predict customer churn and display the confidence score.
